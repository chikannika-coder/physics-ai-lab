## 📥 ขั้นที่ 1: ติดตั้ง Python

### 📸 หน้าจอ 1: ดาวน์โหลด

```
+---------------------------------+
|  python.org                     |
+---------------------------------+
|                                 |
|  +--------------------------+  |
|  | Download Python 3.12     |  |
|  |      [Download]          |  |
|  +--------------------------+  |
|                                 |
+---------------------------------+
```

### 📸 หน้าจอ 2: เลือกตั้งค่า

```
+-----------------------------------+
|  Python Setup                     |
+-----------------------------------+
|                                   |
|  [x] Add Python to PATH <- สําคัญ |
|  [ ] Install for all users       |
|                                   |
|  [Install Now]  [Customize]      |
|                                   |
+-----------------------------------+
```

### ✅ ตรวจสอบ

⌨️ พิมพ์:
```
py -3 --version
```

✅ เห็น: `Python 3.12.x`

❌ ถ้าเห็น: `'py' is not recognized`
-> ลบ Python -> ติดตั้งใหม่ -> ติ๊ก Add to PATH

---

## 📥 ขั้นที่ 2: Clone Repository

⌨️ พิมพ์:
```
cd "D:\"
git clone https://github.com/chikannika/physics-ai-lab.git
cd physics-ai-lab
```

---

## 📥 ขั้นที่ 3: ติดตั้ง Dependencies

⌨️ พิมพ์:
```
py -3 -m pip install -r requirements.txt
```

⏳ รอ 5-10 นาที

---

## 📥 ขั้นที่ 4: ตรวจสอบ

⌨️ พิมพ์ทีละบรรทัด:
```
py -3 -c "import streamlit; print('OK')"
py -3 -c "import numpy; print('OK')"
```

✅ เห็นแบบนี้ทุกบรรทัด: `OK`

## 🐛 แก้ปัญหา

### ปัญหา 1: py: command not found

**แก้:**
1. ลบ Python
2. ติดตั้งใหม่
3. ติ๊ก Add Python to PATH
4. Restart cmd

### ปัญหา 2: ModuleNotFoundError

```
py -3 -m pip install streamlit
```

### ปัญหา 3: Port 8501 in use

```
py -3 -m streamlit run physics_ai_app_v5.py --server.port 8502
```

### ปัญหา 4: Font ไทยเป็นสี่เหลี่ยม

1. ดาวน์โหลด Sarabun
2. Install for all users
3. รันโปรแกรมใหม่
