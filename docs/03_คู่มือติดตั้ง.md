## 📥 ขั้นที่ 1: ติดตั้ง Python

### Windows

1. ดาวน์โหลดจาก python.org
2. **สำคัญ:** เลือก **Add Python to PATH**
3. Install
4. ตรวจสอบ:

```cmd
py -3 --version
```

ควรเห็น: Python 3.10.x หรือสูงกว่า

---

## 📥 ขั้นที่ 2: Clone Repository

```bash
git clone https://github.com/chikannika/physics-ai-lab.git
cd physics-ai-lab
```

---

## 📥 ขั้นที่ 3: ติดตั้ง Dependencies

```bash
py -3 -m pip install -r requirements.txt
```

**หมายเหตุ:** pysr ใช้เวลา 5-10 นาที

## 🐛 Troubleshooting

### py: command not found

**แก้:** ลง Python ใหม่ -> เลือก Add to PATH

### ModuleNotFoundError: streamlit

```bash
py -3 -m pip install streamlit
```

### pysr install failed

```bash
py -3 -m pip install --upgrade pysr
```

### Port 8501 in use

```bash
py -3 -m streamlit run physics_ai_app_v5.py --server.port 8502
```

### Font ไทยเป็นสี่เหลี่ยม

1. ดาวน์โหลด Sarabun
2. คลิกขวา -> Install for all users
3. รันโปรแกรมใหม่
