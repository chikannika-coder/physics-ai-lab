## 2. ส่วนที่ 1: Symbolic Regression

### 2.1 คืออะไร?

AI ที่ค้นหา **สูตรคณิตศาสตร์** จากข้อมูล

| วิธีปกติ | Symbolic Regression |
|---------|---------------------|
| มนุษย์เดาสูตร | AI ค้นหาสูตรเอง |
| ใช้เวลาเป็นวัน | ใช้เวลาเป็นนาที |
| จำกัดด้วยความรู้ | ไม่จำกัด |

### 2.2 ตัวอย่าง: ลูกตุ้ม

**การทดลอง:** แขวนลูกตุ้มที่ความยาว L ต่างๆ, วัดคาบ T

| L (m) | T (s) |
|-------|-------|
| 0.1 | 0.63 |
| 0.4 | 1.27 |
| 0.9 | 1.90 |
| 1.6 | 2.54 |

**AI ค้นพบ:** `T = 6.2832 * sqrt(L)`

**ตรวจสอบ:** `6.2832 = 2π` → ตรงกับทฤษฎี `T = 2π√(L/g)`

## 3. ส่วนที่ 2: PINN Solver

### 3.1 PINN คืออะไร?

Physics-Informed Neural Network = โครงข่ายประสาทที่รู้กฎฟิสิกส์

**Loss รวม = Loss ข้อมูล + Loss ฟิสิกส์**

### 3.2 ตัวอย่าง: สมการความร้อน

สมการ: `∂u/∂t = α ∇²u`

- `u(t,x)` = อุณหภูมิที่ x เวลา t
- `α` = ค่าการแพร่

### 3.3 เชื่อมโยงกับพุทธปรัชญา

| สมการ | ธรรมะ |
|-------|-------|
| u(t,x) | สังขาร |
| ∂u/∂t | อนิจจัง |
| α | กฎธรรมชาติ |
| u → 0 | นิพพาน |

⚠️ เป็นการ **เปรียบเทียบ** ไม่ใช่ **พิสูจน์**
